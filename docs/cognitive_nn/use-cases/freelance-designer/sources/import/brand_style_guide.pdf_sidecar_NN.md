# Verdant Roasters — Brand Identity & Style Guide

## Visual Identity & Color System

### Forest Green Primary Brand Token
Primary brand accent color is `#1B4332`. Represents organic shade-grown coffee canopy. Must be used for primary call-to-action buttons and top navigation banners.

### Warm Cream Background Token
Secondary base canvas token is `#F8F9FA`. Replaces stark pure white to evoke natural parchment and unbleached paper textures.

## Typography & Trust Marks

### Headings and Body Fonts
Headings use `Plus Jakarta Sans` (weights 700 and 800). Body copy uses `Inter` (weight 400).

### Certified Organic Seal
The USDA Organic and Fair Trade Certified SVG badges must be displayed on every product page and in the trust bar above the footer.
