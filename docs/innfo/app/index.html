Retired

The hosted iNNfo app was retired

There is no web app at this address anymore. cogNNitive now works with the domain console, and nothing needs to be uploaded to a server.

What replaces it

The domain console is one self-contained HTML file, domaiNN_console.html, generated locally from your workspace. Open it by double-clicking; it runs offline. Changes are reviewed in the console and applied through changesets, so every edit stays traceable in your plain-text files.

How to get one

Ask your AI agent to regenerate the console with the MCP tool regenerate_console, or run node scripts/export-console.mjs against your workspace.
