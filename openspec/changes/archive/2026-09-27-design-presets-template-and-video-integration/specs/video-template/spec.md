# Capability Spec: `video-preset-binding`

## Description
Extends the Video Level-2 template to support binding a video element to a design preset.

## Requirements

### R1: Video Field Extension
`iNNfo/specs/templates/video/spec_NN.md` MUST include:
- `preset` field on `Video` concept of type `string`.

### R2: Sample Reference
`iNNfo/specs/templates/video/samples/Ghostbusters_V_0-1-0_video_NN.md` MUST include `preset:: [[Ghostbusters Tech Noir]]` or equivalent canonical sample preset.
