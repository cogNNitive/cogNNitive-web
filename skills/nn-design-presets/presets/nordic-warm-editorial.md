# Nordic Warm Editorial (Organic Luxury)

Estilo cálido, orgánico y minimalista de inspiración escandinava y editorial de lujo. Fondo lino cálido, tonos tierra suaves (verde bosque y terracota), con tipografía serif refinada y serenidad visual.

## Core Tokens

```yaml
mode: WARM_LIGHT_ORGANIC
palette:
  canvas_base: "#FDFBF7"
  canvas_inert: "#F4EFEA"
  brand_primary: "#2D4A3E"
  brand_secondary: "#C85A32"
  border_soft: "#E7E5E4"
  ink_primary: "#1C1917"
  ink_muted: "#78716C"

  sans_ui: "'Inter', 'Plus Jakarta Sans', system-ui, sans-serif"

  sm: "4px"
  md: "8px"
  lg: "12px"
```

## Reglas de Aplicación

- **Canvas Lino**: `#FDFBF7` para un tono cálido no cegador, descansado para la vista.
- **Detalles Terracota y Verde**: Verde bosque `#2D4A3E` para elementos de marca principal y estructura; terracota `#C85A32` para llamadas a la acción secundarias o destacados.
- **Tipografía Serif Elegante**: *Lora* en titulares principales para una presencia tipo publicación literaria o revista de diseño.
- **Esquinas Suaves y Bordes Calidos**: Bordes suaves `#E7E5E4` que delimitan sutilmente sin agredir la estructura visual.
