# Neutral frame

The blueprint's default frame (`frame:: neutral`). It declares only the engine's
built-in accent, so a fresh install renders with the same palette and no implicit
typeface — a domain or series adopts a brand frame by shipping
`frames/<name>.md` and setting `frame:: <name>`.
